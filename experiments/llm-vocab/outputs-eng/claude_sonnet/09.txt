A typical request flows through several layers:

1. **Browser** – The user triggers an action (click, form submit); JavaScript sends an HTTP request (often via `fetch`/XHR) to the server.
2. **Network/DNS** – The domain resolves to an IP, and the request travels over TLS to the server, often passing through a load balancer or CDN.
3. **Web server** – Receives the request and routes it (via a reverse proxy like Nginx) to the application server.
4. **Application layer** – Framework routing directs the request to the appropriate controller/handler, which validates input, checks authentication/authorization, and applies business logic.
5. **Database layer** – The app queries the database (via an ORM or driver), the DB executes it and returns results.
6. **Response** – The app formats data (e.g., JSON), sends it back through the server/network to the browser, which updates the UI accordingly.

Each layer adds latency, so caching and connection pooling are commonly used for efficiency.
